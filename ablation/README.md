# Phase 17.5 — Ablation + Signal Discovery

Tests which signal groups add predictive value to the inventory-agnostic market brain.

Models include:
- all signals
- each signal removed one at a time
- individual signals
- selected two- and three-signal combinations

Metric:
- direction accuracy at 1D, 3D and 7D

This is exploratory model selection, not proof of causal predictive power.
The next validation step should be walk-forward significance / confidence intervals.
